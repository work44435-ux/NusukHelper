# Nusuk Helper (Android Studio project)

A small Android WebView wrapper for the public Nusuk code organizer:
https://magdymoo.github.io/Nusuk/

## Build locally
1. Open this folder in Android Studio.
2. Allow Gradle sync and install Android SDK Platform 35 if prompted.
3. Select **Build > Build Bundle(s) / APK(s) > Build APK(s)**.

## Build in GitHub Actions
1. Create a GitHub repository and upload the contents of this folder to its `main` branch.
2. Open the repository's **Actions** tab.
3. Run **Build Nusuk Helper APK** (or wait for the push-triggered build).
4. Open the completed workflow run and download the `NusukHelper-debug-apk` artifact.

## Scope and limitations
- Displays the public code-organizer website inside a standalone Android app.
- The user manually reviews/copies a code, opens the official Nusuk app, and confirms redemption.
- It does not automatically submit codes, loop through redemptions, bypass app controls, or interact with Nusuk servers.
- The official Nusuk app is separate and is not modified.
- This is source code; the APK is generated by Android Studio or the included GitHub Actions workflow.
